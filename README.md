# A10 Control Getting Started Guide

This repository contains a Getting Started guide for the A10 Control platform.

The guide helps first-time network administrators understand the platform and perform the initial steps required to start monitoring and managing devices.

## Scope

- Overview of A10 Control
- Initial setup and prerequisites
- First-time login and basic configuration
- Monitoring dashboards (high-level)
- Initial management tasks such as creating clusters and registering devices

## Audience

This guide is intended for network administrators who have basic knowledge of IP addressing, DNS, NTP, and virtualized environments, but are new to A10 Control.

## Purpose

This documentation project demonstrates the ability to design structured onboarding content from a large reference manual and present it in a clear, task-oriented format.

## Output

The guide is designed for publishing in GitBook and can also be shared as PDF or HTML documentation.
